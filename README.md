# 💕 Love Proposal for Inayat 💕

A beautiful, interactive love proposal created with HTML, CSS, and JavaScript. This romantic web application features stunning animations, floating hearts, fireworks, and a heartfelt message.

## 🌟 Features

- **Animated Hearts**: Pulsing hearts on the welcome screen
- **Floating Hearts**: Continuous animation of hearts floating across the screen
- **Interactive Buttons**: Hover effects and smooth transitions
- **Fireworks Celebration**: Colorful fireworks animation when "YES" is clicked
- **Hearts Rain**: Falling hearts animation during celebration
- **Confetti Effect**: Colorful confetti falling from the sky
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Background Music**: Romantic background music (if browser allows)
- **Smooth Transitions**: Beautiful screen transitions with fade effects

## 🚀 How to Use

1. **Open the Proposal**: Simply open `index.html` in any modern web browser
2. **Start the Journey**: Click "Open My Heart" to begin the romantic journey
3. **Read the Message**: Enjoy the heartfelt messages that appear with beautiful animations
4. **Make Your Choice**: Click "YES! 💕" or try to click "No" (it will move away!)
5. **Celebrate**: If you choose YES, enjoy the fireworks and celebration!

## 💝 Special Features

### The "No" Button
The "No" button has a playful feature - it moves away when you try to click it! After a few attempts, it will eventually show a sad screen, but you can always try again.

### Celebration Effects
When "YES" is clicked:
- Fireworks explode across the screen
- Hearts rain down from the sky
- Confetti falls everywhere
- Background music plays (if enabled)
- Bouncing celebration text

### Mobile Support
- Touch-friendly buttons
- Haptic feedback on mobile devices
- Responsive design for all screen sizes

## 🎵 Audio

The proposal includes background music that will play automatically when the proposal screen is shown. Note that some browsers may block autoplay, but the visual effects will still work perfectly.
